# SCL-250 Leads Funnel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar uma lista comercial protegida de Leads com busca, filtros e paginação.

**Architecture:** Uma query server-side lê Leads existentes com filtros normalizados e ordenação recente; a página Admin reutiliza DataTable, Pagination, EmptyState e padrões de Clientes.

**Tech Stack:** Next.js 16.3, React 19, TypeScript, Drizzle, Vitest.

## Global Constraints

- Sem migration, mutação, transição de estágio, notas ou conversão.
- Leitura exige `staff`/`admin`; quiz é mostrado somente quando já existe no Lead.
- Busca cobre nome, telefone e e-mail; paginação usa limite padrão 25 e máximo 100.
