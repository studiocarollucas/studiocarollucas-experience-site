# SEO and GA4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make public pages indexable with correct metadata and measure public traffic through GA4 without collecting PII.

**Architecture:** Metadata file conventions expose only public routes. A small client-side GA4 adapter is enabled exclusively when `NEXT_PUBLIC_GA_MEASUREMENT_ID` is present; the existing public event facade stays a no-op when GA is absent.

**Tech Stack:** Next.js Metadata APIs, `next/script`, TypeScript, Vitest.

## Global Constraints

- Production config uses `NEXT_PUBLIC_GA_MEASUREMENT_ID=G-0YX9SRS1Y7`.
- Admin, client portal, quiz capture and private Gallery routes are noindex and absent from sitemap.
- GA events contain only allow-listed public event name/source fields; no PII.
- No database migration, third-party analytics SDK, secret, or public Gallery URL belongs here.

```ts
const siteUrl = new URL(process.env.NEXT_PUBLIC_SITE_URL ?? "https://studiocarollucas.com.br");
export default function sitemap(): MetadataRoute.Sitemap {
  return ["/", "/experiencias", "/quiz"].map((pathname) => ({ url: new URL(pathname, siteUrl).toString(), changeFrequency: "weekly", priority: pathname === "/" ? 1 : 0.8 }));
}
```

- [ ] **Step 3: Implement the minimal bridge**

```tsx
export function GoogleAnalytics({ measurementId }: { measurementId?: string }) {
  if (!measurementId) return null;
  return <Script src={`https://www.googletagmanager.com/gtag/js?id=${measurementId}`} strategy="afterInteractive" />;
}
```

Initialize `window.dataLayer` and `gtag("config", measurementId)` after interactive load; `trackPublicEvent` checks `typeof window.gtag === "function"` and forwards only its existing union payload.
